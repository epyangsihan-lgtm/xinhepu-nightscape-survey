## 高德地图配置

网页中的 Web 端 Key 已沿用本地版本。若线上地图提示“鉴权未完成”，还需要为该 Key 配置 `securityJsCode`。为避免将安全密钥提交到公开仓库，当前页面仍使用浏览器本地保存方式；正式公开调研前应配置服务端代理，或确认可接受前端公开后再写入发布版。
